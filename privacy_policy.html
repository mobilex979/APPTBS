Kebijakan Privasi

BUSLIN BROS - Aplikasi Tbs (oleh YY's)
Terakhir diperbarui: 26 September 2026

1. Informasi yang Kami Kumpulkan

Aplikasi ini tidak mengumpulkan data pribadi pengguna. Semua data (nota timbang, data panen, data upah grup, foto nota) tersimpan secara lokal di perangkat pengguna dan tidak pernah dikirim ke server kami atau pihak ketiga.

2. Data yang Dikelola Pengguna

  • Data nota timbang TBS (nomor tiket, berat, tanggal, foto)
  • Data panen per blok dan data upah grup pemborong
  • File backup terenkripsi — hanya dapat dibuka dengan kode yang dimiliki pemilik aplikasi

Pengguna dapat membagikan file backup dan file Excel secara mandiri melalui aplikasi pesan (WhatsApp, email) sesuai keinginan mereka.

3. Izin Aplikasi

  • Kamera & Galeri — untuk memotret nota timbang
  • Penyimpanan — untuk menyimpan data, backup, dan file Excel

Izin ini hanya digunakan untuk fungsi di atas dan tidak untuk mengakses data lain di perangkat.

4. Pemrosesan Teks (OCR)

Pembacaan teks pada foto nota (OCR) dilakukan sepenuhnya di perangkat menggunakan Google ML Kit. Foto tidak dikirim keluar perangkat.

5. Font Aplikasi

Font diunduh sekali saat pertama kali membuka aplikasi (Google Fonts) lalu tersimpan lokal.

6. Hak Pengguna

Pengguna dapat menghapus seluruh data kapan saja melalui menu aplikasi ("Delete All") atau dengan menghapus aplikasi dari perangkat.

7. Kontak

Pertanyaan tentang kebijakan ini dapat ditujukan kepada pengembang melalui kontak yang tertera di materi pemasaran aplikasi.
